# Causal First-Passage & Market Microstructure Research

A Python research framework for predicting fee-covering first-passage states from order-book imbalance and recent state history.

## Research contributions

- Causal rolling distributions with explicit label maturity over a **50-quote-update horizon**.
- Two prespecified models: imbalance conditioning and imbalance plus the latest observable resolved state.
- **48 regression tests**, including a scalar reference model, random-path checks and future-suffix/prefix checks.
- Input-integrity analysis across **20 GOOG sessions / 34,773,653 quote updates**; full-session replay and closed-trade reconciliation for 10 July 2026.
- Explicit execution accounting with entry delay, spreads, fees and position state.

[Interactive project explorer](docs/explorer.html) — download and open the HTML in a browser. GitHub displays its source.

## Research question

Can an observable microstructure state estimate the next fee-covering price barrier, and how do label timing and execution affect the resulting trade path? The model releases labels only after the complete window has matured. This keeps zero outcomes and quick barrier hits on the same information schedule.

Prediction labels describe an opportunity within a horizon. Actual delayed execution is a separately measured outcome. The implementation review and full ledgers document this relationship.

## Datasets

GOOG files contain L1 quote updates. Proxy mode measures event time in quote updates because trade identifiers are absent. TATAMOTORS and INFY contain 10,000 synthetic L5 snapshots each, generated by the supplied L2 simulator with an embedded imbalance/flow relationship. The array-by-array comparison is documented in the [L2 provenance record](https://github.com/shah1403/l2-regime-research/blob/main/verification/synthetic_provenance.json). Supplied GOOG inputs have no recovered vendor/license metadata; no redistribution license is inferred.

## Reproduce

~~~bash
python -m pip install -r requirements.txt
python -m unittest -v test_audited_fp
python audit_data.py
python audited_fp_runner.py --kind nse --path data/nse/orderbook_tatamotors_10000snaps.npz --fee-model nse_intraday --q 1 --allow-proxy-clock --out verification/tata-proxy.json
python audited_fp_runner.py --kind goog --path data/goog/goog_2026-07-10.npz --fee-model per_share --fee-per-share 0.0035 --q 1 --allow-proxy-clock --skip-late-diagnostics --out verification/goog-20260710-proxy.json
~~~

The optional --skip-late-diagnostics flag skips rest-of-session recovery diagnostics while preserving primary predictions and execution accounting. Zeros in skipped late-diagnostic fields mean not computed.
